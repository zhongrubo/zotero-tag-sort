# 安全政策 / Security Policy

## 支持的版本 / Supported versions

| 版本 Version | 支持情况 Supported |
| --- | --- |
| 1.x | 支持 / Supported |
| 0.x | 不支持 / Unsupported |

## 报告漏洞 / Reporting a vulnerability

请勿在公开 Issue 中披露安全漏洞。请通过邮件或私密渠道联系维护者，并提供以下信息：
Please do not disclose security vulnerabilities in public issues. Contact the maintainer privately with:

- 受影响版本。Affected version(s).
- 漏洞描述与复现步骤。A description and reproduction steps.
- 潜在影响。Potential impact.

我们会在确认后尽快修复并发布更新。We will fix confirmed issues and release an update as soon as possible.
